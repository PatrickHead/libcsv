<a id="installation"></a>
## Installation

In the spirit of GNU Autotools, follow these steps to install libcsv:

  1) Obtain libcsv.txz
  2) tar xf libcsv.txz
  3) cd libcsv
  4) make
  5) sudo make install

## Library

A static library named libcsv.a should be installed in /usr/local/lib after running `sudo make install`
